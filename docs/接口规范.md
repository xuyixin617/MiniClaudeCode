# 接口规范

## 通用约定
- 基址：`https://api.example.com/v1`
- 数据格式：JSON，编码 UTF-8。
- 认证：除登录/刷新接口外，一律要求 `Authorization: Bearer <access_token>` 请求头。

## 统一响应结构
成功：`{"code": 0, "data": {...}, "message": "ok"}`
失败：`{"code": <错误码>, "data": null, "message": "<原因>"}`

## 常见错误码
| code | 含义 |
| ---- | ---- |
| 401  | 未认证或令牌失效 |
| 403  | 无权限访问该资源 |
| 404  | 资源不存在 |
| 429  | 触发限流，稍后重试 |

## 分页约定
列表接口统一用 `page`（页码，从 1 起）与 `page_size`（每页条数，默认 20，上限 100）参数。
