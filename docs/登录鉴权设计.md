# 登录鉴权设计

## 概览
本系统采用「账号密码 + JWT 双令牌」方案，实现无状态登录与自动续期。

## 登录流程（共五步）
1. 客户端提交账号密码到 `/api/auth/login`。
2. 服务端校验凭证，失败返回 401 并提示「用户名或密码错误」。
3. 校验通过后签发两个令牌：`access_token`（有效期 15 分钟）与 `refresh_token`（有效期 7 天）。
4. 前端把 access_token 存内存、refresh_token 存 HttpOnly Cookie，避免 XSS 窃取。
5. 后续请求在 `Authorization: Bearer <access_token>` 头携带令牌，由网关统一校验。

## 令牌续期
access_token 过期后，前端调 `/api/auth/refresh` 用 refresh_token 换新令牌；
若 refresh_token 也过期，则强制用户重新登录。

## 关键决策
- 采用 JWT 而非服务端 session，是为了支持水平扩容（无中心会话存储）。
- 登出时把 refresh_token 加入黑名单，防止令牌被重复使用。
